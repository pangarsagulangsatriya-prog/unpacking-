# UNPACKING Landscape Data Acquisition

Repositori untuk mengambil **data geospasial publik** dan menerbitkan hasil akuisisi tanpa akun layanan satelit tambahan. Tidak mengunggah foto atau arsip pribadi.

Source publik: Earth Search, OSM, NASA POWER. Semua hasil harus menyimpan status per sumber dan tanggal unduh. Pattern Lab dibiarkan kosong.
